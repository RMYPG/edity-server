# AGENTS.md

## Tooling

Every development tool is declared in `mise.toml` and run through mise (`mise install`, then `mise exec` or `mise run`). Add a tool to `mise.toml`, pinned, before using it.

## Domain docs

The glossary and decisions live in the `edity` repository (`CONTEXT.md`, `docs/adr/`), and so do the specs and issues (`.scratch/<feature>/`). Use the glossary's terms in code, issues and commits.
